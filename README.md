Unity checkers game project.

## Getting started

- Clone the repository and add `.` to Unity Hub as an existing project.

- Use the recorded Editor version as the starting point. For an upgrade, work on a separate branch and preserve all `.meta` files and serialized asset references.

- Open a project scene in the Editor and enter Play mode. Available scene examples: [Assets/Core/SampleScene/DemoScene.unity](https://github.com/kleberandrade/shadow-checkers/blob/master/Assets/Core/SampleScene/DemoScene.unity), [Assets/Meshs/cena.unity](https://github.com/kleberandrade/shadow-checkers/blob/master/Assets/Meshs/cena.unity), [Assets/Scenes/Credits.unity](https://github.com/kleberandrade/shadow-checkers/blob/master/Assets/Scenes/Credits.unity), [Assets/Scenes/Game.unity](https://github.com/kleberandrade/shadow-checkers/blob/master/Assets/Scenes/Game.unity), [Assets/Scenes/Menu.unity](https://github.com/kleberandrade/shadow-checkers/blob/master/Assets/Scenes/Menu.unity).
